# BrowseAI Privacy Policy

Effective date: November 7, 2026

BrowseAI is an on-device AI assistant that answers questions about the current
web page or selected text using Chrome's built-in Prompt API.

## Data BrowseAI Handles

When you open or use BrowseAI, the extension may handle:

- Visible text and text you select on the current web page
- The current page title, URL, and domain
- Prompts you enter and responses generated by the on-device language model
- Images, audio files, and screenshots you attach to a prompt
- Your settings: theme, color palette, and the optional nickname and custom
  instructions
- If AI Bookmarks is on: the title and URL of pages you open, grouped into
  categories
- Voice recordings, when you click the microphone button or use Dictation
- Notes you save: text you highlight on a page, the AI note about it, and the
  page's title and URL
- Research topics you create: the title, URL and AI-written key points of pages
  you add to a topic
- Page performance data (timings and file sizes) measured by the browser, when
  you use the Performance Explainer

## How Data Is Used

This data is used only to provide BrowseAI's page-aware chat, general chat,
tools, notes, research topics, and AI Bookmarks. Page content, prompts,
attachments, and voice recordings are processed locally by Chrome's built-in
language model.

Some tools change the page only after you click a button: Reply Drafter and
Dictation type text into a text box you picked, Form Filler fills fields you
accept, and Dark Pattern Detector unchecks a box when you click Uncheck. No form
is ever submitted by BrowseAI.

## Storage and Retention

BrowseAI does not save prompts, responses, attachments, or voice recordings.
Chat data, attachments, and recordings are kept in memory only for the current
page session. They are removed when the page reloads, the tab closes, or you
start a new chat. Voice recordings stop after 60 seconds and the microphone is
released as soon as recording ends.

BrowseAI uses the storage permission to save these items in chrome.storage.local
on your device:

- Appearance settings (theme and color palette).
- Personalization settings: (1) your optional nickname, used only to address you
  in responses, and (2) your optional custom instructions, used only to guide
  response style and behavior (for example tone, formatting preferences, or
  constraints you define).
- AI Bookmarks, when turned on: a list of categories, each with the title and
  URL of the pages saved in it. You can delete single pages, whole categories,
  or all bookmarks in the Bookmarks panel, and turn the feature off in Settings.
- Notes, only when you save them: the highlighted text, the AI note, the date, a
  few words around the highlight (to show it again when you come back), and the
  page title and URL. You can delete single notes or whole pages in the Notes
  panel.
- Research topics, only when you add a page: the topic name and, for each page,
  its title, URL, and AI-written key points. You can remove pages or delete a
  topic at any time.

The Dark Pattern Detector keeps the value of countdown timers it checked in the
page's session storage, so it can tell whether a timer restarted after a reload.
This is removed when the tab closes.

This data stays on your device until you change or delete it, or remove the
extension.

## Data Transmission and Sharing

BrowseAI does not transmit page content, browsing information, prompts,
responses, attachments, voice recordings, settings, bookmarks, notes, or
research topics to the developer or to third-party servers. It does not sell,
share, or use user data for advertising, analytics, creditworthiness, or
purposes unrelated to its single purpose.

Chrome may download and manage its built-in language model as part of the
browser. BrowseAI does not send page content or prompts as part of that model
download.

## Site Access

BrowseAI runs on websites the user visits so it can display its assistant and,
when the user opens it, read the current page content needed for page-aware
answers and tools. This access is used only for the extension's user-facing
features.

## Extension Permissions

BrowseAI requests only the permissions needed for its visible features:

- storage: Saves the settings, optional AI Bookmarks, notes, and research topics
  described above in chrome.storage.local.
- activeTab: Enables user-initiated screenshot actions (Capture Visible Area and
  Snip & Capture) on the tab you are currently using.
- Host access to all sites: Shows the assistant on any page and reads the page
  when you use it.

Screenshot data is captured only after a direct user action, used only to answer
the current prompt, and is not transmitted to external servers.

BrowseAI does not request a microphone permission for the extension. When you
click the microphone button, Chrome asks whether the current site may use the
microphone. You can deny or remove that access at any time in Chrome's site
settings.
